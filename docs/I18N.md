# I18N — dictionary module and where it touches the text

Status: done for Bahasa Indonesia (`?lang=id`), 2026-11-05. Every player-facing text goes through `HPO.t` (`_`), the dictionary is split by area in `src/00_lang_id*.js`. **In-world texts stay English on purpose** (LED screen and scoreboards, clubhouse and island signs, banners, court floor, replay line-call sprite, replay badge and IN/OUT verdict): cosmetic, not needed to play. Padel terms stay English. 15-15 is called "Salim" (sama lima) by the umpire, with a commentator joke and a line in the scoring explanation. The sections below are the original map; section 4 (canvas textures) is intentionally not translated.

## The module

- `src/00_i18n.js` — `HPO.mod.i18n`, shortcut `HPO.t`. Loads first after core, no DOM at load, so headless tests get it too.
- `src/00_lang_id.js` (shared words and country names), `00_lang_id_studio.js`, `00_lang_id_play.js`, `00_lang_id_commentary.js` (umpire, ceremony, errors), `00_lang_id_pools.js` (commentary pools and the salim jokes) — all `HPO.mod.i18n.register('id', { ... }, 'id-ID')`; later files win on a duplicate key, so keep a key in one file. Picked up by `build.js` and `devpage.js` by name.
- Country names use the English name as key (`_(country.name)`), because saved players store the English name.
- Language: **English by default**, Indonesian only with `?lang=id` (no auto-detect from the browser, so a half-translated game never surprises anyone). No `localStorage`; a future toggle sets `?lang=` and reloads, because the panels are built once.
- Keys: the **English text as written in the code is the key**. A string the dictionary does not have shows in English, so the dictionary can be filled in bit by bit. `{name}` tokens must stay in the translation.

```js
HPO.t('Pause')                                  // 'Jeda' when ?lang=id and the key exists, else 'Pause'
HPO.t('Continue as {name}', { name: p.name })
HPO.mod.i18n.list('commentary.hold', ENGLISH_LINES)   // pools of lines: dotted key, array value
HPO.mod.i18n.missing()                          // English keys requested but not translated: play through, then read this
HPO.mod.i18n.locale                             // 'id-ID', for toLocaleDateString / Intl
```

`node tools/i18n_tests.js` covers lookup and fallback, and checks every registered dictionary: tokens in a translation match the English key, `commentary.<pool>` keys exist and only use tokens the English pool uses, and every `_('literal')` in `src/` has an Indonesian entry. Labels that come from tables (`_(label)`) are not seen by that scan: play through with `?lang=id` and read `HPO.mod.i18n.missing()`; it was empty after the Play journey, tutorial, a Blitz match, pause menu, match centre and Studio.

## Rules for call sites

1. Call `t()` where the text is **rendered**, not where a table is declared. Tables like `PRESET_LABELS` keep English; wrap the label at the `h(...)` call. (The dictionary is registered before any other module loads, so `t()` at load time also works, but render time is safer.)
2. Translate **whole sentences with tokens**, never fragments joined with `+`. Indonesian word order differs (`'Continue as ' + name`, `'Team ' + t`, `"men's"`, `'World #' + n`, `' · left-handed'`).
3. Never branch on displayed text. The places that do are listed under "Coupling" below; fix them first.
4. The sim keeps returning English codes (`describe().banner`, verdict `IN`/`OUT`, shot ids). `scoring_tests` and `americano_tests` assert them. Translate at the UI edge.

### 2. Text that is data, not code

- **Country names**: `ROSTER[].country.name`, the `NATIONS` table and the `country.name` stored in IndexedDB for visitor players are English. Translate by the three-letter **code** at display time (`t('country.ESP')`), not the stored name.
- **Player names and nicknames** (`El Muro`, `The Scalpel`, `Thunder`, `Viking`, `Glass Hana`): proper names, leave. Archetype labels (`ARCH`) and `left/right-handed` are translatable.
- **Sponsor and tournament names** (Lintas Court Rail, Tapak Smash, `Littleworld Jakarta Padel Cup <year>`): brand names, leave. Only the generic words (`BANK`, `COURT RAIL`, `HOSPITALITY by`) could change.

### 3. Commentary and umpire (`18_commentary.js`) — the hardest part

- `POOL` has about 55 pools of 4–5 lines each; `INTER` (interjections); `COACH_LABEL`; `FAULT_TEXT`.
- The umpire is **composed in code with English grammar**: `NUM`/`ORD` words, `pointWord()` (love/fifteen/thirty/forty), `scoreCall()` ("Advantage X", "Tie-break, zero all"), `gamesPhrase()`, the "Game, set and match, X. 6–4, 6–3." sentence. Each needs a keyed template (`umpire.gameSetMatch` with `{team}`, `{sets}`) and a decision on whether the Indonesian call keeps English tennis words (`love`, `deuce`, `advantage`) or not.
- Pronouns `{he}`/`{his}` exist in `pron()`; Indonesian has no gender pronoun, so those tokens just go unused. A pool may have a different number of lines in Indonesian; the engine only needs the array.
- `cap()` capitalises the first letter; fine for Indonesian.
- Fallback names: `'the player'`, `'Team A'`, `'the server'` are English literals in `pName`/`teamLbl`/`onPhase`.
- Dictionary keys: `commentary.<poolKey>`; the engine reads the pool through `i18n.list(...)` at pick time (to wire).
- Other sources of umpire/commentator text that go through `BUS 'speak'`: `09_match.js:347` (`Challenge from Team X. The call is overturned.`), `09_match.js:363` (`Tactical timeout, Team X.`), and all of `16_replay_ceremony.js` (see section 5).

### 5. Replay, ceremony and speech

- `16_replay_ceremony.js`: `say()` lines (welcome, introductions with country and ranking, coin toss, `Game, set and match. X win 6-4.`, champions) are English sentences with dynamic parts; `banner()` DOM texts; replay badge `EAGLE EYE REPLAY`/`REPLAY`; verdict `IN`/`OUT`; line-call sprite (`labelTex`).
- `17_audio.js` speech: voices are filtered with `/^en/i`, the preferred names are English voices, and `u.lang` defaults to `'en-GB'`. For Indonesian it needs `id-ID` voices, and a quiet fallback (text only) when the device has none. Rate and pitch are tuned for English. `toneKind()` (chime type when speech is off) classifies by English regexes, so translated umpire text silently becomes a plain point chime.

## Layout risks with longer Indonesian text

Indonesian is plain Latin (the loaded fonts have every glyph) but often 15–30% longer.

- **Overflow, no fit logic** (worst first): replay verdict block `labelTex` (52 px, `IN`/`OUT`), notice board and tagline on the island (`12_world_island.js:248, 261-263`), island menu board, clubhouse sign (27 px monospace in 512 px), banners FINAL/CUP, `VIP BOX`, LED footer, small-scoreboard footer, LED team labels truncated to 3–9 characters.
- **Shrink to fit** (safe, may get small): most island signs (`fitText`, floor 8 px), court atlas (`fitFont`, floor 5 px), sponsor strip.
- **DOM**: segment buttons, the dock, the HUD buttons and the callout bursts were sized for English words; check desktop and 390x844.
- Numbers: `toFixed(1)` prints `.`; Indonesian uses `,` (cosmetic, `Intl.NumberFormat(i18n.locale)`).
